# CloverPit: lucky charms and the debt

Reference for [run-design.md](../run-design.md). Effects from the [CloverPit Wiki](https://cloverpit.wiki.gg/wiki/Lucky_Charms) (CC BY-SA). Icons in the original text are written as [Name]; [666] is the devil symbol that takes coins.

## How the run works

- Each deadline has 3 rounds; each round you pull the lever 7 times ("most spins") or 3 times ("fewer spins", more tickets). The lever has a cost, so playing itself costs a fee.
- Coins go into the ATM; the debt must be met by the end of the deadline or the floor opens. Interest: 7% of the deposit each round.
- Charms are bought with tickets in a store of 4; restocks cost more each deadline. The telephone offers 1 of 3 abilities each deadline.
