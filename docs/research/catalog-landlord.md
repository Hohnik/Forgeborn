# Luck be a Landlord: symbols, items and rent

Reference for [run-design.md](../run-design.md). Effects from the [Luck be a Landlord Wiki](https://luck-be-a-landlord.fandom.com/wiki/Symbols) (CC BY-SA). Symbols written as [Name].

## How the run works

- A 5x4 slot machine shows symbols from your inventory; after each spin you add 1 of 3 offered symbols (or skip). Rent is due after a set number of spins; pay 12 rents to win, then climb 20 floors.
- Items are passive; essences are one-use versions of items. Removal tokens remove a symbol, reroll tokens reroll the offer.

| Floor | Adds |

| 2 | Rent 7 is 25 more expensive |

| 9 | Obtain one fewer from emails |
| 10 | 1 Dud is added every 25 spins before rent payment 12 |
| 11 | Landlord has 250 more HP |
| 12 | Start with 3 Duds instead of 2 Duds |
| 13 | Landlord has 750 more HP (Replaces Floor 11 effect) |
| 14 | 1 Dud is added every 20 spins before rent payment 12 (Replaces Floor 10 effect) |
| 15 | Landlord uses more challenging fine print |
| 16 | Obtain one fewer from emails |
| 17 | Landlord uses 2x more fine print |
| 18 | Rent 9 is 25 more expensive |
| 19 | 1 Dud is added every 15 spins before rent payment 12 (Replaces Floor 14 effect) |
| 20 | Landlord uses 3x more fine print (Replaces Floor 17 effect) |
