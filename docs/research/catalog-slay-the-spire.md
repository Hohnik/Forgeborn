# Slay the Spire: relics

Reference for [run-design.md](../run-design.md). Effects from the [Slay the Spire Wiki](https://slay-the-spire.fandom.com/wiki/Relics) (CC BY-SA).

**179 relics**, no slot limit: Common 36, Uncommon 36, Rare 34, Boss 30, Shop 20, Event 18, Starter 4, Special 1. Boss relics are strong with a drawback; shop relics only from the merchant; event relics from events.
