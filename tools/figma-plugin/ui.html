Draw the addon's window here, move and resize things, then read it back as UI/Layout.lua.

Start from another Layout.lua

Paste your current UI/Layout.lua here; the plugin starts with the layout it was made with.

2 · Edit in Figma

  • Move and resize the layers. Each one is named after its Layout.lua entry (forge, nextSwing, …): keep the names.
  • Text layers: only their position and width count.
  • Item rows (workbench, shelf, …): change the gap in the auto layout panel.
  • Order cards: edit card-1, the main component; the other cards follow it.
  • A window pasted or dropped in as SVG works too.

3 · Back to the addon

Select anything in the window (if there is more than one), then read it.

Paste it over UI/Layout.lua in the Forgeborn addon folder, then /reload in game.
